## Reason

Owner requires LAN feasibility to be proven before deep business implementation so the project does not invest heavily in APK/Web/Service behavior that later depends on an unstable LAN design.

## Owner-approved constraints

- PDA must automatically enable LAN mode when the valid BETA LAN service is available.
- Physical test capacity is approximately 3 PDA simultaneously + 1 laptop.
- Larger capacity tests may use synthetic logical clients on the laptop, but synthetic load is not equivalent to RF/Wi-Fi evidence.
- Android and LAN Agent must both expose automatic update discovery/notification and a separate manual update path for recovery.
- LAN Agent must be lightweight but not invisible: background Windows service plus tray/settings console with status, update, local database/data-directory selection and operational controls.
