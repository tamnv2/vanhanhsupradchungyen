## Reason

Owner requested three usability/diagnostic corrections before physical LAN testing on the restricted corporate laptop:

1. Agent should expose simple CPU/RAM/Disk/Network status similar to a tray system monitor.
2. Pilot metrics/status labels must explain what they mean and why they matter.
3. Agent and Android APK need one-action diagnostic export so physical test evidence can be uploaded to the VHDCHY ChatGPT session for analysis.

All changes must remain compatible with the established no-admin / no-router-access constraint.

## Exact changes

### Windows LAN Agent

- Added V2 user-mode entrypoint while preserving the previous source for traceability.
- Added no-admin system telemetry sampler using Windows user-mode APIs:
  - whole-laptop CPU load;
  - whole-laptop RAM used percent;
  - used percent of the drive containing Agent data;
  - aggregate active-interface network throughput;
  - Agent-process CPU;
  - Agent-process working-set RAM.
- Tray tooltip refreshes every 2 seconds with CPU/RAM/Disk/Network summary.
- Added tray action `Trạng thái nhanh / Giải thích thông số` with plain-language descriptions.
- Rebuilt local dashboard with descriptions under every metric.
- Added bounded rotating `agent-diagnostic.log`.
- Added `Xuất log chẩn đoán...` in tray using a normal user `SaveFileDialog`.
- Added loopback-only dashboard download `/api/pilot/diagnostics/export`.
- Diagnostic ZIP contains `summary.json`, README and diagnostic logs only; it intentionally excludes `pilot.db` and business data.
- Release package README now tells the tester how to inspect tray metrics and export evidence.

### Android LAN Pilot APK

- Added `MainActivityV2` on top of the existing transport implementation to preserve tested LAN behavior.
- Added a lightweight diagnostic snapshot recorder that captures changes in transport/status/endpoint/queue into app-internal storage.
- Added `Xuất log chẩn đoán` button.
- Export uses Android `ACTION_CREATE_DOCUMENT`; no storage-management permission is required.
- Export TXT includes app/device version, current transport, endpoint, queue, current status, saved pilot endpoint state, device sequence and bounded diagnostic history.
- UI now explains Transport states, endpoint, hysteresis streaks, Echo/Latency, durable event, manual endpoint, local queue and update purpose.

### Build/release

- Windows Agent assembly version is now derived from `GITHUB_RUN_NUMBER`, matching the LAN Pilot prerelease numbering.
- APK version already follows the same workflow run number.

## Security / privacy

- No Admin requirement added.
- No router/DNS/firewall modification added.
- No automatic upload endpoint to a public service was introduced.
- Direct automatic delivery to ChatGPT was intentionally not implemented because the current chat has no authenticated inbound file API for these clients. Tester exports locally and uploads the resulting ZIP/TXT into the project chat.
- Export intentionally avoids raw SQLite business/test database content. Local LAN IP/endpoint may appear because it is required for network diagnosis.
